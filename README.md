# Big Data Learning Repository

This repository is a tracking and learning resource for Big Data technologies, including R, Hadoop, Spark, and SQL.

## 📚 Contents

This repository is organized into four main sections:

- **[R](./R/)** - Statistical computing and data analysis with R
- **[Hadoop](./Hadoop/)** - Distributed storage and processing framework
- **[Spark](./Spark/)** - Unified analytics engine for large-scale data processing
- **[SQL](./SQL/)** - Structured Query Language for database management

## 🎯 Purpose

This repository serves as a comprehensive learning and tracking resource for students studying Big Data technologies. Each section contains:
- Code examples
- Exercises and projects
- Learning notes
- Best practices

## 🚀 Getting Started

### First Time Setup
1. **[Setup Guide](./SETUP.md)** - Install and configure R, Hadoop, Spark, and SQL
2. **[Resources](./RESOURCES.md)** - Curated learning materials and documentation
3. **[Contributing](./CONTRIBUTING.md)** - Guidelines for adding your own content

### Explore the Sections
Navigate to each technology folder to explore specific topics and exercises:

```bash
cd R/        # For R programming exercises
cd Hadoop/   # For Hadoop framework examples
cd Spark/    # For Apache Spark projects
cd SQL/      # For SQL queries and database work
```

## 📖 Learning Path

1. **SQL** - Foundation for data querying and manipulation
2. **R** - Statistical analysis and data visualization
3. **Hadoop** - Distributed data storage and MapReduce
4. **Spark** - Advanced distributed data processing
